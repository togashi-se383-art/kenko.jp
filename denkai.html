解説ノート（クーロンの法則）

解説ノート（電界の強さ）

1. 静電力の大きさ

真空中（空気中）で、点電荷 Q₁、Q₂ [C] を r [m] 離して置いたとき、両電荷の間に働く静電力 F [N] は

F = k × Q₁Q₂ / r²　　k = 1/(4πε₀) ≒ 9×10⁹

「二つの点電荷の間に働く静電力の大きさは、両電荷の電気量の積に比例し、電荷間の距離の2乗に反比例する」（静電気に関するクーロンの法則）。

2. 距離の2乗に反比例

距離を2倍にすると力は 1/4、3倍にすると 1/9 になります。「r を 2 倍」ボタンや、グラフの印で確かめましょう。

3. 力の向き

同種の電荷は反発力、異種の電荷は吸引力です。力は両電荷を結ぶ直線上にあり、Q₁ と Q₂ に働く力は大きさが等しく、向きが反対です。

4. 物質の中では

k = 1/(4πε)、ε = ε₀εr なので、F = 9×10⁹ × Q₁Q₂ / (εr r²) となり、比誘電率 εr の分だけ力が小さくなります。

5. 計算の注意

  • μC は ×10⁻⁶ C、cm は ÷100 して m に直してから代入します。
  • 初期値は教科書の例題（3 μC と 4 μC を 30 cm 離す → 1.2 N の反発力）です。

6. 電界とのつながり

Q₁ が Q₂ の位置につくる電界の強さを E₁ とすると、F = Q₂E₁ と書けます。続きは「② ある点の電界の強さ」で確かめましょう。

1. 電界の強さとは

電界中に 1 C の正電荷を置いたとき、これに働く静電力の大きさと向きを電界の強さといい、量記号 E、単位 V/m で表します。

2. 点電荷がつくる電界の強さ

真空中で、Q [C] の点電荷から r [m] 離れた点 P の電界の大きさは

E = 1/(4πε₀) × Q / r² = 9×10⁹ × Q / r² [V/m]

クーロンの法則で、相手の電荷を 1 C にしたものです。距離の2乗に反比例します。

3. 電界の向き

正電荷がつくる電界は電荷から遠ざかる向き、負電荷がつくる電界は電荷に近づく向きです。電気力線の向きと一致します。

4. 電界の中に置いた電荷が受ける力

F = qE [N]（教科書の式 F = QE）

置いた電荷が正なら E と同じ向き、負なら逆向きに力が働きます。

5. 電気力線との関係

電気力線は Q/ε 本出ていて、半径 r の球面 1 m² あたりの本数が電界の強さ E になります。点 P を通る点線の円がその球面（の断面）です。

6. 例題

初期値は教科書の例題（空気中に 6×10⁻⁶ C の点電荷、50 cm 離れた点 → 2.16×10⁵ V/m）です。
