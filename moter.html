条件を変える

θ：コイルの面と磁界（N→S）のなす角

動かしてみる

「手を離す」と、トルクでコイルが回り出します（回る速さは見やすさ優先の目安）。

解説ノート（式の意味）

1. 導体1本にはたらく力 F

磁束密度 B [T] の磁界の中で、長さ l [m] の導線に電流 I [A] を流すと、F = B I l [N] の力がはたらきます。向きはフレミングの左手の法則で決まります。コイルの辺には導線が N 本ならんでいるので、辺全体では

F = N B I l [N]

2. 回す力（トルク）＝ 力 × 腕の長さ

腕の長さは「回転軸から、力の向きの線（作用線）までの距離」です。力 F は上下向きなので、腕は横方向の距離 (b/2) cosθ になります。

3. 式をつなげる

導体①と②の2本が、同じ向きにコイルを回すので

T = 2 × F × (b/2) cosθ = F b cosθ
　= N B I l b cosθ = N B I A cosθ [N·m]

（l × b = A：コイルの面積）

4. θ = 90° で T = 0 になるのはなぜ？

θ = 90° でも、力 F は同じ大きさではたらいています。しかし力の線が回転軸を通るので腕の長さが 0 になり、T = 0 になります。「手を離す」で試すと、コイルは面が磁界と垂直になる位置で止まります。

回り続けさせるには、半回転ごとに電流の向きを入れかえます。これが直流モーターの整流子のはたらきです（「整流子をつける」で確認できます）。

5. 角度のとり方に注意

この画面の θ は「コイルの面と磁界のなす角」です。教科書によっては「コイルの面に垂直な線（法線）と磁界のなす角 φ」を使い、T = NBIA sinφ と書きます。φ = 90° − θ なので、どちらも同じ意味です。

6. 画面の見方

  • 磁力線の本数は B に比例します。
  • 黄色の矢印（力 F）の長さは F に比例します（2.5 N で基準の長さ）。長すぎ・短すぎのときは上限・下限の長さで表示し、注記が出ます。
  • 緑の線が腕の長さ、ピンクの円弧がトルクです。円弧の長さは「そのときの最大トルクに対する割合」、矢印は回る向きを表します。
  • ⊙ は電流が手前に向かって、⊗ は奥に向かって流れることを表します。
  • 「手を離す」の回る速さは見やすさのために調整した目安で、実際のモーターの回転数ではありません。
